# Research: MP3 Android Player (Flutter)

## Research Tasks

### Technical Unknowns
- **Android SDK Minimum Version**: Determine the recommended minimum SDK for `just_audio` and `file_picker` compatibility.
- **Audio Focus Handling**: How to properly implement `just_audio` with Android's audio focus system to handle interruptions (calls, other music).
- **Background Playback**: Investigation into `audio_service` integration with `just_audio` to ensure playback continues when the app is in the background.
- **Scoped Storage Permissions**: Best practices for using `file_picker` on modern Android versions (API 30+) to access MP3 files.

### Technology Best Practices
- **just_audio**: Best patterns for managing streams of audio position and duration.
- **file_picker**: Optimal way to handle file selection and permission requests on Android.
- **Flutter Architecture**: Recommended way to structure a service-oriented Flutter app (e.g., using `get_it` or `Provider`).
